Custom tools


Please make sure all ports are valid, and multiple ports are separated by commas.

Specify custom ports to send the parsed data to, separated by commas.

Custom rules

Custom rules can be used to override the parser selection. When a rule's regular expression matches with the url of the problem that is being parsed, the parser configured in that rule is used instead of the default parser.

Request timeout

This timeout is applied both when a problem is sent to the ports a tool could possibly be listening on and when a parser fetches problem pages (for example when parsing a whole contest). It prevents requests to ports with no listening tools, or to slow judges, from being kept alive for too long. Increase it if your tools do not receive the problem data after clicking the "+" button, or if contest parsing times out. Page requests always get at least 15 seconds regardless of this value.

Debugging

If debug mode is enabled, all the JSON data that is sent is logged to the console as well.
